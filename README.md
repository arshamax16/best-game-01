Embergarden is a luminous arcade survival game: you are Luma, a firefly keeper of the last lantern in a dark garden. Gather golden embers to feed your light, chain fireflies for combos, dodge the shadow wisps that hunger for your glow — and when the eighth wave breaks, banish the Moth King and bring back the dawn.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with the mouse or WASD / arrow keys, dash with Space or click, pause with P, mute with M.
